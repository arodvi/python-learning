# Week 02 | Functions, Lambdas and Object-Oriented Programming

[Open the Jupyter notebook](Week_02_Functions_Lambdas_and_OOP.ipynb)

This English-language practice notebook covers **COMP7022 Lectures 4–6**. It contains **20 guided exercises**, **6 adapted Class 5 practical tasks**, and **1 identified student-written average-function example**.

## Coverage
- **Lecture 4, Exercises 01–10:** function definitions, parameters and arguments, `return` versus `print`, `*args`, `**kwargs`, local/global/nonlocal scope, closures, multiple return values, and recursion.
- **Lecture 5, Exercises 11–16:** `lambda`, `map()`, `filter()`, `reduce()`, and combinations of higher-order functions.
- **Lecture 6, Exercises 17–20:** defining classes, instance methods and state, class versus instance attributes, and method composition.
- **Class 5, Practical 01–06:** recursive Fibonacci, filtering multiples, matching pairs, summing nested lists, factorial with `reduce()`, and a higher-order function.
- **Confirmed student-written snippet:** an average calculator with an explicit parameter and returned result.

## What the notebook demonstrates
- Separating a function's returned value from displayed output.
- Passing functions as arguments and processing collections.
- Managing scope and state deliberately.
- Organizing related behavior into Python objects.

Open the notebook in Jupyter Notebook or JupyterLab with a **Python 3** kernel and use **Run All**. The examples use standard-library modules such as `functools`, `math`, and `operator`; no external dataset is required. Repository-wide setup guidance is in the [COMP7022 README](../README.md).
