# Week 01 | Python Foundations and Data Structures

[Open the Jupyter notebook](Week_01_Python_Foundations_and_Data_Structures.ipynb)

This English-language practice notebook covers **COMP7022 Lectures 1–3**. It contains **18 guided exercises** and **8 adapted practical tasks** from Class 2 and Class 3.

## Coverage
- **Lecture 1, Exercises 01–05:** variables, types, conditionals, `for` and `while` loops, and simple statistics.
- **Lecture 2, Exercises 06–12:** lists, nested lists, dictionaries and their views, sets, and tuple unpacking.
- **Lecture 3, Exercises 13–18:** comprehensions, slicing, and an average calculator.
- **Class 2, Practical 01–05:** divisibility, filtering names, common values, index calculations, and tic-tac-toe win detection.
- **Class 3, Practical 06–08:** grouping names by initial, inverting a dictionary, and a small hash-table implementation with collision handling.

## What the notebook demonstrates
- Working with core Python collections, loops and conditionals.
- Choosing between list positions, dictionary keys and hash-based lookup.
- Expressing transformations with comprehensions.
- Structuring a small exercise into readable, testable steps.
