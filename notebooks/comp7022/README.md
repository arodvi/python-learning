# COMP7022 Python Learning Portfolio

A structured, executable collection of Python learning exercises completed and reviewed while studying for an MSc in Artificial Intelligence.

## What is included?

| Week | Notebook | Topics |
| --- | --- | --- |
| 01 | [Python foundations](week-01/Week_01_Python_Foundations_and_Data_Structures.ipynb) | Python syntax, loops, collections, comprehensions, slicing; adapted Class 2 and Class 3 practical tasks |
| 02 | [Functions and OOP](week-02/Week_02_Functions_Lambdas_and_OOP.ipynb) | Functions, scope, recursion, higher-order functions, classes; adapted Class 5 practical tasks |
| 03 | [Inheritance and NumPy](week-03/Week_03_Inheritance_Exceptions_and_NumPy.ipynb) | Inheritance, abstract classes, exceptions, NumPy manipulation and storage; 26 guided exercises and review tasks |

> These notebooks are **educational practice**, not standalone industrial projects. Their purpose is to show progression, coding fundamentals, reasoning, and code review skills.

## Solution provenance

- **Guided/reconstructed reference solutions** are marked clearly. They were organized from prior study sessions and are not presented as verbatim student-authored submissions.
- **Confirmed student-written snippets** are explicitly identified where available.
- University task prompts are **paraphrased**. Original slides, PDF handouts, exam materials, and restricted/course proprietary datasets are not included.
- Week 3 includes targeted corrections for common misconceptions (abstract methods, indexing, `axis`).

## Run locally or in Jupyter

1. Install Python 3.10+ and JupyterLab (or open the notebooks in an existing Jupyter environment).
2. `python -m pip install -r requirements.txt`
3. Open a notebook and select the Python 3 kernel.
4. Use **Run All** to execute cells in order. No external datasets are required.
